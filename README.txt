CHIBI CROSSHAIR STUDIO

Başlatmak için Release klasöründeki "Chibi Crosshair Studio.exe" dosyasına çift tıklayın.
"Chibi Simge Güncelleyici.exe" dosyasını aynı klasörde tutun.

FARE İMLEÇLERİ
- Listedeki 17 karakter pozundan birini seçerek önizleyin.
- İmleç boyutu, resim boyutu ve tıklama noktası X/Y değerleri seçtiğiniz imlece özeldir.
- "Resim boyutu (%)" çizimi küçültür; imlecin piksel boyutunu değiştirmez.
- "Seçili imleci uygula" yalnızca listedeki imleci günceller.
- "Windows açılınca imleçleri uygula" seçiliyse kayıtlı imleçler oturum açınca yeniden uygulanır.
- "Yeni simgeleri indir" ile ayrı güncelleyiciyi açın. GitHub depo adresini girip
  eklenen yeni PNG'leri indirerek seçtiğiniz Windows imlecine uygulayın.

NİŞANGÂH
- Renk, çizgi uzunluğu, boşluk, kalınlık, saydamlık ve konumu ayarlayın.
- "Ekranda göster" ile ekran ortasındaki nişangâhı açın veya kapatın.
- Nişangâh uygulama açıkken görünür. Bazı tam ekran oyunlar masaüstü katmanlarını göstermez.

Karakter PNG dosyaları assets klasöründe bulunur. Uygulama çalışmak için
ayrıca Python gerektirmez; temel görseller EXE dosyasının içine de eklenmiştir.
GitHub'dan indirilen simgeler kullanıcı klasöründe saklanır. Yayınlama ve katalog
hazırlama adımları için README.md dosyasına bakın.
